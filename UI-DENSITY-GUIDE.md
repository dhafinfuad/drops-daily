# UI Density Guide — v0.6.1

This version keeps the compact/dense component geometry from v0.6.0, with two deliberate adjustments:

1. Component padding is increased by approximately 1 px compared with v0.6.0.
2. Vertical spacing between major sections is restored to the more relaxed rhythm used before the dense pass.

The intent is: compact controls and cards, but enough breathing room between groups so the screen does not feel cramped.
